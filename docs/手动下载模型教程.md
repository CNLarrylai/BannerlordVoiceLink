# 模型手动下载教程(国内加速)

> 给评论区/置顶用。链接均为 hf-mirror.com 国内镜像,2026-08 实测可直连下载
> (支持断点续传)。**v0.9.3 起软件已内置镜像,正常情况下点一下就能自动下,
> 这份教程是给"自动下载还是失败"的兜底方案。**

## 先搞清楚:你需要下载吗?

| 情况 | 要不要下 |
|---|---|
| 刚订阅,想直接玩 | **不用!** small 模型已内置在模组里,开箱即用 |
| 有 N 卡,想要最强识别 | 下 `large-v3-turbo`(还需 GPU 加速库,见文末) |
| 想要中等档 | 下 `medium` |

## 二、放到哪里(v0.9.4 起超简单)

**把同一个模型的所有文件,放进以模型名命名的文件夹里**,位置:

```
%LOCALAPPDATA%\BannerlordVoice\models\<模型名>\
```

复制这一行粘到文件资源管理器地址栏按回车,就能直达(没有 models 文件夹就自己建):

```
%LOCALAPPDATA%\BannerlordVoice
```

放好后长这样:

```
BannerlordVoice\
└── models\
    └── large-v3-turbo\        ← 文件夹名必须和模型名一致
        ├── model.bin
        ├── config.json
        ├── preprocessor_config.json
        ├── tokenizer.json
        └── vocabulary.json
```

下 medium 就建 `medium` 文件夹,下 small 就建 `small`,以此类推。

## 三、让软件用上它

1. 打开语音面板(启动器)→ **音频设置**
2. 模型那里选 `large-v3-turbo`(或你下的那个)
3. 保存 → 重启语音指挥

黑窗里出现 `[STT] 模型就绪` 就成功了。

---

## 四、N 卡玩家还需要 GPU 加速库

模型只是"识别的大脑",要让显卡跑得动它还需要 CUDA 运行库(约 1.2GB):

- **推荐**:v0.9.3 起,有 N 卡的话首次启动会自动弹窗引导,点一下就下载
  (已走国内镜像,不用梯子)
- 手动:音频设置 → 「下载 GPU 加速库」按钮

**没下加速库就选 turbo 的话,会用 CPU 硬跑,一句话要 6 秒**,不如用默认的
small(1.7 秒)。所以顺序是:**先装加速库,再换 turbo**。

## 常见问题

**Q:下完了软件还是说找不到模型?**
A:检查两点:①文件夹名必须**和模型名完全一致**(如 `large-v3-turbo`,不能写成
`turbo` 或 `large-v3`)②`model.bin` 必须直接躺在那个文件夹里,不要再套一层。

**Q:我没显卡,要下这些吗?**
A:不用。内置的 small 在纯 CPU 上就有满命中率,直接玩。

**Q:下载还是很慢/断了?**
A:这些链接支持断点续传,用 IDM 或迅雷这类下载工具会更稳。

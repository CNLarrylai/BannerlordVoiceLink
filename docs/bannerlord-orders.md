## 编队选择 (数字键) 🔵

| 键 | 作用 |
|---|---|
| `1`~`8` | 选中编队 1~8 (Group0Hear~Group7Hear) |
| **`0`** | **全军听令 (EveryoneHear)** — 不需要挨个按 1234 |
| `Backspace` | 打开指令面板 (ViewOrders) |
| `F9` | 返回/收起指令菜单 (SelectOrderReturn) — 可用于兜底关闭卡住的菜单 |

## 顶层 F 键 🟢 (2026-07 用户游戏截图确认)

> 布局说明: 这是用户当前版本(配置 version 5.1)的**原版默认**菜单, 并非 mod 所致。
> 与网上老攻略(F3=队形)不同, 应以本表为准 —— 新版把队形挪到了 F2。

**只有 F1/F2/F3 有子菜单; F4~F9 都是直接生效的单键。**

| 键 | 作用 | 类型 |
|---|---|---|
| F1 | 移动子菜单 | 菜单 |
| **F2** | **队形子菜单** | 菜单 |
| F3 | 行为子菜单 (朝向/射击/上马/委派/转移) | 菜单 |
| F4 | 自由射击 ⇄ 停止射击 | 直接切换 |
| F5 | 上马 ⇄ 下马 | 直接切换 |
| F6 | 委派指挥 (交给 AI) | 直接 |
| F7 | 朝向方向 | 直接(之后鼠标指向) |
| F8 | 盾墙 (快捷) | 直接 |
| F9 | 线阵 (快捷) | 直接 |

## F1 移动子菜单 🟢 (2026-07 用户游戏截图确认)

| 序列 | 游戏内文字 | 含义 |
|---|---|---|
| F1+F1 | 就位 | 移动到光标指定位置 |
| F1+F2 | 随我来 | 跟随玩家 |
| F1+F3 | 冲锋 | 冲锋 |
| F1+F4 | 开战 | 前进交战 |
| F1+F5 | 退后 | 后撤 |
| F1+F6 | 立定 | 停止/原地 |
| F1+F7 | 撤退 | 退出战场 |
| F1+F9 | 返回 | 收起菜单 |
| F1+F8 | (无) | — |

## F2 队形子菜单 🟢 (2026-07 用户游戏截图确认)

| 序列 | 游戏内文字 |
|---|---|
| F2+F1 | 线阵 (亦可用顶层快捷键 **F9**) |
| F2+F2 | 盾墙 (亦可用顶层快捷键 **F8**) |
| F2+F3 | 散阵 |
| F2+F4 | 圆阵 |
| F2+F5 | 方阵 |
| F2+F6 | 楔阵 (**推荐念「三角阵」** — 楔形/锥形生僻难识别) |
| F2+F7 | 纵列 (**推荐念「排成一列」最稳** — 纵列难念; 竖排易被听成"射排") |
| F2+F8 | 乱阵 |
| F2+F9 | 返回 |

> 词典里 **线阵→F9、盾墙→F8** 走顶层单键(最常用, 少按一次); 其余队形走 F2 子菜单。

## F3 行为子菜单 🟢 (用户截图; 各项也可用顶层直接键)

| 序列 | 游戏内文字 | 备注 |
|---|---|---|
| F3+F1 | 朝向方向 | =顶层 F7 |
| F3+F2 | 自由射击 | =顶层 F4 |
| F3+F3 | 上马 | =顶层 F5 |
| F3+F4 | 委派指挥关闭 | =顶层 F6 |
| F3+F5 | 转移 | 语音不适用 |

> 词典里的射击/上马/委派/朝向都走**顶层单键**(F4/F5/F6/F7), 比子菜单少一步。

## 全部已核实 🟢

所有指令键位已由用户游戏内截图确认 (2026-07)。之前的 bug: 我按网上老攻略把队形设成
F3 前缀, 但新版原版菜单里 F3 是行为菜单(F2=自由射击), 队形其实在 **F2** ——
导致"盾墙"发成了"自由射击"。教训: 键位以用户实测为准, 老攻略会过时。

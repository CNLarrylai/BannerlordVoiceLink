## 分镜

### ① 冷开场(0:00-0:20)不解说,纯实况
战斗最胶着处(推荐自定义战斗,四兵种齐全,敌方带弓箭手+骑兵):
1. 喊「**爸爸打我!**」→ 全军冲锋,顶部金字横幅弹出(给横幅一个特写)
2. 打两秒,喊「**风紧,扯呼!**」→ 全军撤退
3. 黑屏打字幕:「以上没有按任何一个键」→ 进标题

### ② 这是什么(0:20-1:00)
一句话:"我给骑砍做了个用嘴指挥的模组。"
连喊演示(选实测 100% 稳的词,节奏拉满,每条 0.1 秒响应):
> 步兵盾墙 → 弓箭手散开 → 骑兵三角阵 → 全军前进 → 自由射击 → 停止射击
镜头留意:顶部横幅逐条弹、浮层逐条亮。
⚠ 演示避开「圆阵」「乱阵」(易错声学词);圆形队形用「围成圈」喊。

### ③ 核心亮点(1:00-3:00)
1. **看哪打哪**:混战中喊「打他们!」→ 集火你眼前那支敌军(讲一句你
   自己的真实感受:骑马砍人根本腾不出手按 F 键,现在用嘴就行)
2. **点名进攻**:「骑兵,进攻弓箭手!」→ 我方骑兵定向扑向敌方弓箭手,
   顶部横幅报"骑兵 → 进攻敌方弓箭手(N人)"(特写)
3. **骑马激战全程指挥**:双手不离缰绳,连续调度全军(这段是老玩家的
   共鸣点,骑砍指挥之痛一句带过,不展开)

### ④ 整活系统(3:00-4:00)
"这些骚话指令是一个可以随时热切换的整活包——以后直播间观众打赏就能
解锁新指令。"现场演示:改一行配置 → 按 F10 → 「万箭齐发!」生效。
(这段是在预告未来直播的互动玩法,埋直播间引流钩子)

### ⑤ 花絮 + 收尾(4:00-5:00)
- 错听花絮 10 秒:「冲锋」被听成「春风」照样冲(它认识我的口音),
  一句带过"它会越用越懂你"
- CTA:工坊订阅一键装(免费) + "语音数据共建"一句话(你的声音会让它
  变得更强) + "想看它是怎么被做出来的,评论区告诉我"←给第二季探路
